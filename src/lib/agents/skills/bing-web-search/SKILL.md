# 必应外网搜索

## 何时使用

- 用户要找**尚未入库**的工具、竞品或官网，或需要**最新**信息。
- 已用 `searchNavWebsites` 查库无匹配，需要外网补充。

## 如何执行

1. 确认已配置环境变量 `BING_SEARCH_API_KEY`（Azure 必应搜索资源）。
2. 调用工具 **`webSearch`**，传入精简中文或英文查询词；必要时增加站名、产品名以提高精度。
3. 对返回的条目：**不得编造** title、url、snippet；仅整理工具输出。
4. 建议每条注明「外链来源：必应摘要」，由管理员自行二次甄别后入库。

## 限额与错误

- 未配置密钥时工具会返回明确错误，请如实告知管理员配置方式。
- 单次请求条数由工具侧限制，避免一次索要过多全文。
